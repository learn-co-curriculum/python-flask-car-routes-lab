# Flatiron Cars - Car Routes Lab


## Overview
A Flask application that provides routes for a car company database. Users can visit the homepage or request information about a specific car model.


## Routes
  /

  Displays a welcome message.

  /<model>

  Checks whether a car model exists in the company's fleet, and displays a message to the user identifying if it exists or not.


## Installation and Setup
- Clone this repository.

- Install dependencies using pipenv install.

- Activate the virtual environment using pipenv shell.

- Running the Application


## Start the Flask application:

  flask --app server.app run

- Open http://127.0.0.1:5000/ in your browser to access the application.
